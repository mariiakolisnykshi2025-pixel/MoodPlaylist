# MoodPlaylist 🎧
**Live Demo:** [//mariiakolisnykshi2025-pixel.github.io/MoodPlaylist/](//mariiakolisnykshi2025-pixel.github.io/MoodPlaylist/)

A responsive web application that generates personalized music playlists based on the user's current emotional state and genre preferences using the YouTube Data API v3.

## 🌟 Features
* **Mood-Based Music Selection:** Select from 10 distinct mood presets (e.g., *Romanticising your life*, *Creating epic edits in your head*, *Longing for the past*).
* **Dynamic Genre Filtering:** Available genres dynamically adjust depending on the chosen mood.
* **Real-Time YouTube Search:** Fetches real-time video results using YouTube Data API v3, displaying custom cover thumbnails, track titles, and direct links.
* **Modern Dark UI:** Styled with a sleek purple/zinc color palette, interactive button states, and smooth visual feedback.
* **Fully Responsive:** Custom mobile-friendly layout optimized for both desktop and small screens.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure and interactive sections.
* **CSS3:** Custom layout (Flexbox), CSS variables, dark theme palette, and responsive `@media` queries.
* **JavaScript (ES6+):** Dynamic DOM manipulation, Event Handling, and Asynchronous programming (`async/await` Fetch API).
* **API:** YouTube Data API v3.
